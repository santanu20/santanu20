# Santanu Panda

Building local-first AI infrastructure in Rust.

- [Blazar](https://github.com/santanu20/blazar) — a multi-engine local LLM inference platform: llama.cpp, mistral.rs, SGLang, and MLX behind OpenAI- and ollama-compatible APIs, with durable jobs, federation, speech, and vision lanes.
- Everything Apache-2.0/MIT, built for any OS and any hardware.
